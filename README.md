# Richman Calicut — website

Scroll-driven 3D hero for Richman, Collections & Designs (Ram Mohan Road, Calicut).

The chalk-stripe double-breasted jacket from the shop mannequin comes apart into its
cut pattern pieces (fronts, back, sleeves, peak lapels, collar, pocket flaps, buttons)
as you scroll, then is rebuilt around the form.

- `index.html` — single file; Three.js r128 from cdnjs, fonts from Google Fonts.
- Open it directly in a browser or serve the folder (`python3 -m http.server`).
- Falls back to a plain text stack with `prefers-reduced-motion` or without WebGL.
